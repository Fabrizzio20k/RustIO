# Sensor MQ135 (calidad del aire / gases) en Raspberry Pi 5

El MQ135 es un sensor ANALÓGICO: su salida AOUT es un voltaje que varía con la
concentración de gases (CO2, NH3, NOx, alcohol, humo, etc.). La Raspberry Pi NO
tiene entradas analógicas, así que necesitas un conversor analógico-digital (ADC).
El más común es el MCP3008 (8 canales, bus SPI).

## Cableado

MQ135:
- VCC  -> 5V (pin físico 2). El calentador interno del MQ135 requiere 5V.
- GND  -> GND.
- AOUT -> salida analógica; va a un canal del MCP3008 (p. ej. CH0).

IMPORTANTE (protección de 3.3V): el AOUT del MQ135 puede acercarse a 5V, pero los
GPIO de la Pi son de 3.3V. Alimenta el MCP3008 (VDD y VREF) a 3.3V y pon un divisor
de tensión en AOUT (p. ej. 10kΩ arriba + 20kΩ abajo) para que el canal del ADC
nunca supere ~3.3V.

MCP3008 -> Raspberry Pi (SPI0):
- VDD  -> 3.3V
- VREF -> 3.3V
- AGND -> GND
- DGND -> GND
- CLK  -> SCLK (GPIO11, pin físico 23)
- DOUT -> MISO (GPIO9,  pin físico 21)
- DIN  -> MOSI (GPIO10, pin físico 19)
- CS   -> CE0  (GPIO8,  pin físico 24)

Habilita SPI en la Pi: `sudo raspi-config` -> Interface Options -> SPI -> Enable.

## Dependencia (instálala con la tool install_packages)
- `adafruit-circuitpython-mcp3xxx` (arrastra `Adafruit-Blinka` automáticamente).

## Ejemplo de script `mq135.py`

```python
import time
import board
import busio
import digitalio
from adafruit_mcp3xxx.mcp3008 import MCP3008
from adafruit_mcp3xxx.analog_in import AnalogIn

# Bus SPI y selección de chip (CE0)
spi = busio.SPI(clock=board.SCLK, MISO=board.MISO, MOSI=board.MOSI)
cs = digitalio.DigitalInOut(board.D8)
mcp = MCP3008(spi, cs)

# MQ135 conectado al canal 0 del MCP3008
canal = AnalogIn(mcp, 0)

# Parámetros del montaje (ajústalos / calíbralos)
RL = 10.0     # resistencia de carga del módulo en kΩ
R0 = 76.63    # resistencia en aire limpio; CALIBRAR por sensor

def leer():
    voltaje = canal.voltage      # 0..3.3 V
    raw = canal.value            # 0..65535
    if voltaje <= 0:
        return raw, voltaje, None
    rs = (3.3 - voltaje) / voltaje * RL      # resistencia del sensor
    ratio = rs / R0
    ppm = 116.6020682 * (ratio ** -2.769034857)  # curva típica CO2 (aprox.)
    return raw, voltaje, ppm

while True:
    raw, v, ppm = leer()
    if ppm is None:
        print(f"raw={raw} v={v:.3f} (lectura inválida)")
    else:
        print(f"raw={raw} v={v:.3f}V  CO2~{ppm:.0f} ppm")
    time.sleep(2.0)
```

## Reglas importantes del MQ135
- PRECALENTAMIENTO: el sensor necesita estabilizar antes de dar valores fiables
  (de varios minutos hasta ~24 h la primera vez). No confíes en las primeras lecturas.
- CALIBRACIÓN: `R0` (resistencia en aire limpio) se mide por sensor; el valor del
  ejemplo es orientativo. La conversión a ppm es aproximada, no de precisión.
- Alimenta el calentador a 5V, pero protege el ADC para que el canal no pase de 3.3V.
- Si solo necesitas una tendencia ("más/menos contaminado"), usa el valor crudo
  (`raw`) o el `voltaje` sin convertir a ppm: es más robusto y no requiere calibrar.
